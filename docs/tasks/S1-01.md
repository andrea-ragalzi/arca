### Decisions

- **Same-frame guard.** `_unhandled_input` already ignores key echoes. Two separate presses flushed in one frame, though, would hit two different pickups, because the first pickup is disabled immediately and the second press then picks the next nearest. `try_interact` now records `Engine.get_process_frames()` when it acts and refuses a second action in that frame.
- **`try_interact` return value** stays `true` whenever a target existed, including refusals such as the panel without a fuse or the medkit at full health. A press on a real target is consumed as input. The bool from `interact()` reports whether the world changed and is available to future callers.
- **Panel and supply scripts call `room._notify` / `room._collect_supply`** through duck typing instead of a new public API. This keeps the mission edit inside the listed functions. S1-04 can rename these if a public notice method is ever added.
- **Room descendants only** (`is_ancestor_of`), so interactables in another scene or a test harness root are never offered.
