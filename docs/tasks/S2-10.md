### Render comparison

Godot 4.5.1 Standard, X11, OpenGL 3.3 Compatibility, NVIDIA GeForce RTX 3050 Laptop GPU, driver 580.159.03, 1280 × 720. VSync disabled and Dummy audio. Each matched view warmed for 60 rendered frames and was sampled for two seconds without readback. The FPS column reports the lowest mean among that area's views. The P95 and P99 columns report the highest frame time percentile among its views. Frame timings are wall-clock time between renderer callbacks and include engine and driver work.

| Area | Views | Minimum mean FPS before → after | Worst P95 before → after | Worst P99 before → after |
| --- | ---: | ---: | ---: | ---: |
| Maintenance | 3 | 294.5 → 429.7 | 4.80 → 3.47 ms | 7.26 → 4.55 ms |
| Security | 4 | 242.0 → 427.7 | 5.56 → 3.34 ms | 8.25 → 4.98 ms |
| Control office | 3 | 525.7 → 753.6 | 3.39 → 2.10 ms | 4.20 → 2.98 ms |
| Lift and freight | 4 | 843.5 → 1187.9 | 2.05 → 1.35 ms | 2.61 → 1.94 ms |

The uncapped TPS walk sampled rendered frames while movement input was held. It measured 61.98 seconds of movement in each run. Mean FPS went from 409.3 to 588.7. P95 went from 6.51 ms to 4.21 ms and P99 from 8.41 ms to 5.49 ms. The 60 FPS frame budget is 16.67 ms.

Most of the draw-call reduction comes from removing the directional fill's shadow pass across the route and keeping shadows on the local inspection and room lights. The static figure excludes dynamic pursuit and GPU readback. Camera and route checks cover the sampled openings and side-wall angles. Free-play combat readability, the subjective audio mix and sustained FPS during an active chase remain open. The rendered fixture occasionally emits the inherited camera physics interpolation warning in both revisions.

To repeat the architecture sample, create an output directory and run this from the project directory with the RTX offload environment in `scripts/godot_common.sh`:

```bash
"$GODOT_BIN" --display-driver x11 --rendering-method gl_compatibility --audio-driver Dummy \
  -s res://arca/tools/review_interiors.gd -- /absolute/output/directory
```

Append `walk` to use the real TPS route fixture. The baseline is the same tool over a clean export of `126d223`.
