### Resulting behavior

- **ALERT** plays `Ferocious_Roar` instead of idle. Duration is the unchanged 0.7 s, now the named constant `ALERT_DURATION`.
- An accepted hit enters the new **HURT** state, appended to the enum so existing values stay stable. It needs:
  - state ALERT, CHASE, WINDUP or RECOVER;
  - `stagger_cooldown_remaining <= 0`.
- HURT lasts `stagger_duration` (0.5 s): no movement, no turning, no warning marker, then CHASE. It emits `staggered`.
- `stagger_cooldown` (1.5 s) starts when the stagger starts. It counts down in `_physics_process`, so pause and `stop_combat()` freeze it.
- A hit during WINDUP therefore cancels that bite.
- **Decision:** a committed ATTACK is never interrupted. The windup is the interrupt window, which keeps the bite readable and the existing 0.24 s damage contract intact.
- A WAIT hit still goes to ALERT. DORMANT stays immune. EMERGE takes damage without staggering, as the existing ambush assertion requires. A lethal hit always wins.
- Telemetry label `STAGGERED`.
