# ARCA — Prototipo 0.1

Primo incremento giocabile: stanza industriale TPS, robot nemico, salute, coperture, morte e riavvio.

**Per iniziare:** apri `project.godot` in Godot **4.5.1 Standard**, attendi l'importazione e premi **F5**. In alternativa, apri `arca/test_room.tscn` e premi **F6**.

Controlli: WASD, mouse, destro per mirare, sinistro per sparare, spazio, R per riavviare, Esc per la pausa.

[Guida completa](ARCA_SETUP.md) · [Test eseguiti](TEST_RESULTS.md) · [Crediti](ATTRIBUTIONS.md)

Questa versione usa robot e geometrie provvisori. Dinosauro e puzzle sono i prossimi incrementi.
